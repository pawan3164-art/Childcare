# API Service

NestJS modular monolith backend. Modules (planned): identity/tenancy, care (attendance/daily records), family/communication, medication/incidents, billing/ledger, ccs-integration, notifications.

Not yet scaffolded with `nest new` — this happens when Stage 0 (Foundations) work starts. Structured logging (pino), OpenTelemetry tracing and Sentry are wired in as part of Stage 0, before any feature module — see `/CLAUDE.md`.
